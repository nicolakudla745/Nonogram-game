# Nonogram Puzzle Game
## Overview
This project is an interactive Nonogram puzzle game developed as part of my Computing NEA. Nonograms are logic-based puzzles where players use numerical clues to fill in a grid and reveal a hidden picture.
The application includes a user account system, multiple difficulty levels and a competitive leaderboard.

## Features
- **User Login System:** Users can create accounts and log in. User information is stored in JSON files.
- **Three Difficulty Levels:** Players can choose between three levels of difficulty.
- **Real-Time Leaderboard:** Scores are updated dynamically, allowing users to compare their performance.
- **Daily Puzzle:** A new puzzle is available each day, which each user can complete only once.
- **User Data Storage:** JSON is used to store login information and relevant user data.

## How to Use
1. Run the application.
2. Register a new account or log in using existing credentials.
3. Select a difficulty level or access the daily puzzle.
4. Solve the Nonogram by using the numerical clues to determine which cells should be filled.
5. View your performance on the leaderboard

## Project Development
The project was developed independently, with the development process documented throughout.
This included designing and implementing the login system, managing user data, developing the puzzle functionality and creating the real-time leaderboard.
